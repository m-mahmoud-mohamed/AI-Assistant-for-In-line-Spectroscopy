6. Decide go or no-go from validation and installation feasibility.

- **Samples:** Select retained petroleum samples spanning the client-agreed water-content range and relevant liquid states.
- **References:** Obtain water-content comparison values using a reference method agreed with the client.

- **Comparison:** Compare candidate methods separately on the retained samples against reference water-content values.
- **Validation:** Validate each candidate on independent material excluded from calibration, using acceptance criteria agreed with the client before testing.
- **Go / no-go:** Proceed only if independent-material performance meets the agreed criteria and AFS confirms the proposed installation; otherwise revise or stop the concept.
- **Not demonstrated:** Do not treat a retained-sample result as proof of remote in-line performance.
