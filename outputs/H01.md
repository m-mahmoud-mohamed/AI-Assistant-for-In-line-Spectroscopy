## Recommendation
- **NIR · diffuse reflection probe** — PRIMARY, evidence Strong. NIR diffuse reflection probes are suited to scattering media, including powders.[^TABLE-nir_diffuse_reflection_probe] In-line API concentration monitoring has been reported in the feed frame of a rotary tablet press.[^S01-p14-blend-potency]
  - Limitations: Overlapping NIR bands mean chemometric approaches are likely needed for quantitative and qualitative analysis of spectral data.[^S01-p10-nir-chemometrics]
- **Raman · probe** — COMPARISON, evidence Strong. A published pharmaceutical set-up used a Raman contact probe with an excitation wavelength of 785 nm.[^S01-p15-raman-785]
  - Limitations: Fluorescence background can overwhelm Raman signals from many organic compounds.[^S01-p11-raman-fluorescence] The weak Raman effect requires specialised probes.[^S01-p05-raman-weak]
- **NIR + Raman · combined measurement (only after each method is assessed alone)** — SCREENING, evidence Strong. NIR and Raman provide complementary chemical information.[^S01-p15-nir-raman-complementary] Compare the methods separately on retained samples before choosing a method or testing their combination.
  - Conditions: For a combined test, use same-spot, time-aligned measurements with dedicated processing of the fused data.
  - Limitations: Whether combining the methods improves performance for the new formulation is unknown. _(unknown)_

## Spectral range
- NIR: 780–2500 nm; fiber: VIS-NIR silica fiber. The nominal NIR range is 780–2500 nm.[^S01-p10-nir-range] The usable range depends on the instrument, fiber and probe and is specified for the selected system.
- Raman: Raman shift in cm⁻¹; detection region 400–1100 nm; fiber: UV-VIS silica fiber, VIS-NIR silica fiber. Raman detection happens in the 400–1100 nm visible/short-wave NIR region.[^S01-p11-raman-region] Raman spectra are reported as Raman shift in cm⁻¹, separate from the excitation wavelength.[^S01-p11-raman-shift] The usable range depends on the instrument, fiber and probe and is specified for the selected system. State the excitation wavelength separately from the Raman shift and choose it with the sample's fluorescence and the instrument in mind. Fluorescence background from many organic compounds can overwhelm the Raman signal.[^S01-p11-raman-fluorescence]

## Risks and uncertainty
- The effect of the formulation change on the existing calibration's bias is unknown. _(unknown)_ Effect: Potentially biased API concentration estimates. Mitigation: Evaluate unchanged calibration against independent API reference results.
- NIR reflection is sensitive to sample surface characteristics.[^S01-p17-reflection-surface] Effect: Physical changes may confound concentration estimates. Mitigation: Include representative powder presentation variation in testing.
- Combined measurements on heterogeneous samples require the same sample spot and synchronized data.[^S01-p08-same-spot][^S01-p08-synchronisation] Effect: Misleading apparent gains from combining methods. Mitigation: Verify common sampling spot and synchronise acquisition.

## First feasibility experiment
**Objective:** Test whether the existing NIR calibration remains valid for the new formulation.

1. Clarify intended use, references, criteria, range, timing and access.
2. Prepare representative samples spanning relevant concentration and physical states.
3. Obtain independent API reference values with matched sampling times.
4. Set up probes; compare unchanged calibration, individual models, then fusion.
5. Validate on independent material excluded from model development.
6. Apply client-agreed criteria for go or no-go.

- **Samples:** Prepare representative new-formulation samples across the client-agreed API concentration range and relevant powder and operating states.
- **References:** Obtain independent API concentration values using a client-agreed reference method with sampling matched to the spectral measurements.
- **Set-up:** Collect NIR diffuse-reflection and Raman spectra at the agreed measurement point, ensuring same-spot, time-aligned sampling for any combined measurements.
- **Comparison:** Compare the unchanged existing calibration with separately developed new-formulation NIR and Raman models before testing a combined model with dedicated data-fusion processing.
- **Validation:** Validate each candidate on independent new-formulation material excluded from model fitting and selection.
- **Go / no-go:** Base go/no-go on acceptance criteria agreed with the client before testing.
- **Not demonstrated:** Whether the existing calibration is valid for the new formulation, with or without adding Raman, is unknown. _(unknown)_
