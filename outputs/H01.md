## Recommendation
- **NIR · diffuse reflection probe** — PRIMARY, evidence Strong. NIR diffuse reflection probes are suited to scattering media such as powders.[^TABLE-nir_diffuse_reflection_probe] Overlapping NIR absorption bands suggest the use of chemometrics for quantitative and qualitative analysis of spectral data.[^S01-p10-nir-chemometrics]
  - Limitations: NIR reflection is sensitive to sample surface characteristics.[^S01-p17-reflection-surface]
- **Raman · probe** — COMPARISON, evidence Strong. A Raman contact probe was used in the published pharmaceutical set-up.[^S01-p15-raman-785]
  - Limitations: Fluorescence background can overwhelm Raman signals from many organic compounds.[^S01-p11-raman-fluorescence]
- **NIR + Raman · combined measurement (only after each method is assessed alone)** — SCREENING, evidence Strong. NIR and Raman provide complementary chemical information.[^S01-p15-nir-raman-complementary] Compare the methods separately on retained samples before selecting one or testing a combination.
  - Conditions: Test the hypothesis of added value from combined measurements using same-spot, time-aligned sampling and dedicated processing of fused data.

## Spectral range
- NIR: 780–2500 nm; fiber: VIS-NIR silica fiber. The nominal NIR range is 780–2500 nm.[^S01-p10-nir-range] The usable range depends on the instrument, fiber and probe and is specified for the selected system. The broad absorption bands observed in this region overlap, suggesting the use of chemometrics for quantitative and qualitative analysis of spectral data.[^S01-p10-nir-chemometrics]
- Raman: Raman shift in cm⁻¹; detection region 400–1100 nm; fiber: UV-VIS silica fiber, VIS-NIR silica fiber. Raman detection happens in the 400–1100 nm visible/short-wave NIR region.[^S01-p11-raman-region] Raman spectra are reported as Raman shift in cm⁻¹, separate from the excitation wavelength.[^S01-p11-raman-shift] The usable range depends on the instrument, fiber and probe and is specified for the selected system. State the excitation wavelength separately from the Raman shift and choose it with the sample's fluorescence and the instrument in mind. Fluorescence background can overwhelm the Raman signal of many organic compounds.[^S01-p11-raman-fluorescence]

## Risks and uncertainty
- The existing NIR calibration's validity for the new formulation is unknown. _(unknown)_ Effect: Potentially unreliable API concentration estimates. Mitigation: Compare unchanged-model predictions with independent reference values.
- Combined measurements of heterogeneous samples can be difficult to achieve with the same sampling spot and synchronized acquisition times.[^S01-p08-same-spot][^S01-p08-synchronisation] Effect: Mismatched powder observations confound combined data. Mitigation: Verify overlap and timing; use dedicated processing.

## First feasibility experiment
**Objective:** Test whether the existing NIR calibration is valid for the new formulation and whether Raman provides additional value.

1. Agree reference method, acceptance criteria, concentration range and process constraints.
2. Collect representative existing- and new-formulation samples across agreed variability.
3. Obtain independent reference API concentrations matched to spectral samples.
4. Assess methods separately before comparing combined data using dedicated processing.
5. Validate on independent batches against agreed criteria.
6. Decide go or no-go from independent comparisons.

- **Samples:** Prepare representative samples of the existing and new formulations spanning the client-agreed API concentration range and relevant powder states.
- **References:** Obtain independent reference API concentrations for samples matched to the spectral measurements using the agreed reference method.
- **Set-up:** Assess NIR diffuse reflection and Raman separately before testing a combination that measures the same spot at aligned times.
- **Comparison:** Compare agreement with reference concentrations for the unchanged NIR calibration, formulation-specific single-method models and, only after their assessment, a combined model using dedicated data-fusion processing.
- **Validation:** Validate on independent new-formulation batches excluded from model development against criteria agreed with the client before testing.
- **Go / no-go:** Proceed only if independent validation meets the client-agreed criteria for API concentration tracking under the intended process conditions.
- **Not demonstrated:** Adding Raman has not been demonstrated here to preserve the existing NIR calibration’s validity for the new formulation. _(unknown)_

## Decision basis
Base the go/no-go decision on comparison with reference concentrations on independent new-formulation material against acceptance criteria agreed with the client before testing.
